# Ulua Rt Derive

Procedural derive macros (`UserData`, `FromLua`) for ulua-rt, the mlua-style API of ulua (pure-Rust Luau).

### Add to your project

```toml
[dependencies]
ulua-rt-derive = "0.1.0"
```
