# Ulua Web

WebAssembly bindings to run and type-check Luau in the browser (Rust).

### Add to your project

```toml
[dependencies]
ulua-web = "0.1.0"
```

This crate is consumed via the `ulua` umbrella or by the WebAssembly build pipeline. See the repository for build instructions.
